# ProductionIncidentLog

Android 原生生产事故与异常管理系统。

## 已实现
- Android 原生 Java 工程，最低支持 Android 7.0（API 24）。
- SQLite 本地数据库，现场断网可登记和查询。
- 事故类型：设备损伤、物料混料、人员受伤。
- 班组：A班、B班；区域：造粒、仓库。
- 设备档案统一维护，登记时从设备列表选择，预置滚筒、除湿机。
- 事故编号自动生成；记录事故经过、事故分析、事故原因、当下采取措施、未来预防措施。
- 记录整改负责人、整改期限；支持待整改、整改中、已完成状态更新。
- 事故档案搜索和详情查看。
- 自定义日期范围，并组合班组、区域、事故类型、设备进行统计。
- 首页基础看板与统计分布。

## 构建
GitHub Actions 自动执行 `gradle assembleDebug`，并上传 Debug APK 构建产物。
